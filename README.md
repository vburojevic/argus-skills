# Argus Agent Skills

Exact mirror of the versioned Agent Skills shipped by [Argus](https://github.com/vburojevic/argus/tree/main/skills).

Install through the Argus CLI with `argus skills install` (or refresh with `argus skills update`).
Install skills and MCP configuration together with `argus agent setup`.
Install through the universal skills CLI with `npx skills add vburojevic/argus-skills`.
